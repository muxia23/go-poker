# 账号与三级权限 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 把 go-poker 改成必须用邀请码注册、登录后才能访问的私人站，支持 root/admin/user 三级权限和可修改的唯一用户名。

**Architecture:** 新增不依赖牌局代码的 `backend/auth`，与牌局共用同一数据库。`backend/server` 负责路由、会话守卫和 WebSocket 绑定账号；`backend/table` 只增加 UUID 接管座位和 UUID → 名字映射。

**Tech Stack:** Go 1.26、chi、modernc SQLite、bcrypt、Next.js 静态导出、Playwright e2e。

**Spec:** `docs/superpowers/specs/2026-11-01-accounts-design.md`

## 约定

- `backend/auth` 公开类型：`Account{ID, Username string; Role Role; Disabled, MustChange bool; CreatedAt, LastLogin int64}`；角色常量 `RoleRoot`、`RoleAdmin`、`RoleUser`。
- 错误：`ErrUsernameTaken`、`ErrBadUsername`、`ErrBadPassword`、`ErrBadInvite`、`ErrBadLogin`、`ErrRootProtected`、`ErrLimited`。
- `serveWs(hub, w, r, acct *auth.Account)`：`acct == nil` 只允许单元测试传入，用于保留上游大量按名字建连的测试；生产入口 `Server.serveWebsocket` 没有有效会话时返回 401，永远不会传 nil，并由专门测试覆盖。
- `server.New` 在 `DATABASE_URL` 为空时返回错误，不退回无登录模式。

## HTTP 接口约定（前后端共同遵守）

所有路径都带 `/poker` 前缀。JSON 请求和响应。失败返回对应状态码和 `{"error": "中文提示"}`。POST 校验 Origin。

| 方法与路径 | 权限 | 请求 | 响应 |
|---|---|---|---|
| `POST /poker/api/auth/login` | 公开 | `{username,password}` | `{account}`，写 Cookie；限频时 429 |
| `POST /poker/api/auth/register` | 公开 | `{username,password,invite}` | `{account}`，写 Cookie；限频时 429 |
| `POST /poker/api/auth/logout` | 登录 | | `{}`，清 Cookie，断开该账号的连接 |
| `GET /poker/api/auth/me` | 登录 | | `{account}` |
| `POST /poker/api/auth/password` | 登录，含 MustChange | `{current,password}` | `{account}`，写新 Cookie，断开其他连接；current 错误 403，MustChange 时不校验 current |
| `POST /poker/api/auth/username` | 登录 | `{username}` | `{account}`；在牌桌上 409，重名 409 |
| `GET /poker/api/admin/accounts` | root | | `{accounts:[Account]}` |
| `POST /poker/api/admin/accounts/{id}/role` | root | `{role:"admin"\|"user"}` | `{}` |
| `POST /poker/api/admin/accounts/{id}/disabled` | root | `{disabled:bool}` | `{}`，禁用时断开连接 |
| `POST /poker/api/admin/accounts/{id}/reset-password` | root | | `{password}`，只显示一次，断开连接 |
| `GET /poker/api/admin/invites` | root | | `{invites:[Invite]}` |
| `POST /poker/api/admin/invites` | root | | `{code}`，只显示一次，7 天有效 |
| `POST /poker/api/admin/invites/{id}/revoke` | root | | `{}` |

`Account` 和 `Invite` 的 JSON 字段见 `backend/auth/auth.go`。

- 未登录访问 API 返回 401，页面返回 302 到 `/poker/login?next=...`；MustChange 账号除 `/password`、`/me`、`/logout` 和登录页外，API 返回 403，页面跳转 `/poker/login?change=1`，WebSocket 返回 401。
- 登录页 `/poker/login` 由 Go 内嵌，前端不实现。
- WebSocket 地址 `/poker/ws`。消息里的 `username` 被服务端忽略，前端可发空字符串，用 `joined-table` 返回的名字显示。
- 非 root/admin 发 `create-table` 收到现有 `error` 消息，文案 `only admins can create tables`。
